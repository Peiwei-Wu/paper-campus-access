# 论文校园直达

可自行配置学校的非官方 Chrome 扩展。把论文链接转换为本校的授权访问链接，沿用当前浏览器的学校登录状态。可以继续使用 Clash，无需修改代理配置。

**通用配置工具，不是“所有学校装好即用”。** 支持以下两种方式；是否可访问全文取决于学校订购范围和访问系统。

| 访问方式 | 支持情况 |
| --- | --- |
| WebVPN 的 `/https/编码/路径` 地址 | 设置页面添加各数据库映射 |
| EZproxy 等 `login?url=论文网址` 入口 | 设置页面填写学校 URL 模板 |
| 纯 CARSI / Shibboleth / OpenAthens 机构登录 | 不提供通用自动登录；若同时有支持的代理入口，可配置该入口 |
| 只有 VPN 客户端的学校 | 本扩展不能代替 VPN 客户端 |

## 安装

1. 下载 ZIP，解压到长期保留的文件夹，例如 `C:\BrowserExtensions\paper-campus-access`。
2. Chrome 地址栏打开 `chrome://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的文件夹。
4. 在弹出的“学校设置”页配置学校并保存。以后可右键扩展图标 →“选项”修改。

不要删除或移动已加载的文件夹。安装过同类扩展时，请先停用旧扩展，避免快捷键冲突。

## 配置学校

### WebVPN

1. 填写学校名称和学校 WebVPN 首页地址。
2. 选择“WebVPN 地址映射”。
3. 从学校门户打开某个数据库，将原始数据库网址和通过学校打开后的网址分别粘贴到两个输入框。
4. 点击“添加 / 更新此网站”，按需添加其他数据库，再“保存学校设置”。

要求学校地址符合 `/https/编码/路径` 或 `/http/编码/路径` 格式。不符合时不能直接套用；不同学校、不同域名的编码不能随意混用。不要粘贴含登录票据的回调地址。

### EZproxy / URL 模板

1. 填写学校名称及学校代理门户首页地址。
2. 选择“EZproxy / URL 模板”。
3. 按学校图书馆公布的代理前缀填写模板，例如：

```text
https://ezproxy.your-university.edu/login?url={encodedUrl}
```

以上仅是格式示例，必须换成自己学校的真实域名。模板与门户必须同源，且包含一个 `{encodedUrl}`，表示经过 URL 编码的论文地址。

4. 填入允许转换的论文网站域名，每行一个，例如 `www.nature.com`，保存设置。

## 日常使用

本人完成一次学校登录后，照常在 Google Scholar 搜索论文。打开出版社论文页后：

- 按 **Ctrl + Shift + Y**；或点击扩展按钮。
- 也可右键论文链接 →“通过本校打开论文”。

在新标签页通过学校通道打开，登录有效时沿用学校会话。到期后需本人重新登录。DOI 或其他中转地址请先打开出版社页面再使用。

增加网站只需进入“选项”添加并保存，不需要改代码，也不需要刷新扩展。快捷键冲突时，到 `chrome://extensions/shortcuts` 修改。

## 权限与验证范围

只申请 `activeTab`、`contextMenus`、`storage`；配置保存在本机，不包含账号密码，不读取 Cookie、正文或浏览历史，不改变 Clash，不自动抓取或下载论文。保留少量文章编号查询参数，不转发其他跟踪或认证参数；依赖特殊参数的网站可能需要适配。

## 文件

`manifest.json`：扩展声明；`background.mjs`：按钮与菜单；`route.mjs`：链接转换及验证；`options.html` / `options.mjs`：学校设置；`style.css`：样式；`help.html`：使用帮助；`README.md`：本说明。
